# Casino V2 — アセット納入版（UX-08 #223）

**状態：ユーザーが画像・代表SFXの最終デザインを採用／GitHub バイナリ登録待ち。まだゲームには組み込んでいない。**

## 方向性

- デザイン名：Emerald Nocturne。深い緑フェルト、チャコール、控えめな金色の光。
- AS-01=B / AS-02=A / AS-03=A / AS-04=A / AS-05=C。
- 通常は落ち着いた物理音、重要イベントは短いシネマティック効果音。BGM / Voice は無し。
- Card 52種、Chip額面・正本のゲーム状態を画像にしない。D60、D92、D135～D143、D49を優先する。
- 既存9 PNGと README画像は変更もコピーもしていない。元のアセットが配信画面に使用済みだとは仮定しない。

## 使い方

- 各アセットの公開URL、ピクセル寸法、形式、アルファ、SHA-256、容量、起源、対応Event、Fallbackは `manifest.json` を参照。
- `/assets/casino-v2/backgrounds/casino-ambient-desktop.webp` 等を CSS 等の表示層が選択してよい。CSS を使用しない/ロード失敗では既存の単色背景に戻すこと。
- オーバーレイは RGBA 透過がある。All-in / Showdown / Winner の正本や値は Event Log にあり、画像は描画だけを担う。
- `sfx/` は `.ogg` (Opus) と `.mp3` 互換音源。ブラウザ再生・ミュート・重複抑制・音量調節・CPU時系列との同期は #225 の範囲。
- `preview.webp` は試作のコンタクトプレビュー。実際のゲーム画面を表すものではない。
- ファイル名に意味があるため Claude Code は勝手に別画像・別音源へ差し替えず、不明点は #223 へ返す。

## 制作由来・ライセンス

- 背景の原画像は ChatGPT の画像生成機能による新規生成。それ以外のテクスチャ、光彩、音はプロシージャル合成による新規制作。既存の第三者画像・収録音声・商用サウンドライブラリの複製・ダウンロードなし。
- `manifest.json` の `source` は生成由来の記録で、第三者の著作権に関する保証や専用のライセンス許諾を意味しない。公開配布時はOpenAIの利用条件と、既存素材の権利整理を別途確認する。
- `/docs/assets/casino-v2/` の一式は納入・検収資料であり、ゲームプレイ用の新規UIやAPIを変更しない。

## 受け入れ基準

- デザインの視認性：小画面/大画面で Poker UI の実額・手番・カード・Dealer 裁定が主役。画像に文字、未公開札、Chip 額面、架空の Pot を含めない。
- 画像は必要十分な大きさと容量。無透過背景は写真、透明素材は実際の RGBA にする。
- SFX は短く、極端なクリッピングが無く、無音時にも操作不能にならない。
- React / CSS / Engine の製品コードの変更はなし。GitHubでの音声・画像バイナリ納入はアップロード経路を検証後にPR化する。
