# 初期UIアセットの追加

## 概要

ユーザー提供の `proj-poker-assets.zip` からPNG画像10点を指定の配置・ファイル名で追加し、README冒頭にヒーロー画像を挿入する。関連: #2。

## 変更内容

- `apps/web/public/assets/table/`: テーブル背景2点
- `apps/web/public/assets/cards/`: カード裏面1点
- `apps/web/public/assets/ui/`: ロゴ・ディーラーボタン各1点
- `apps/web/public/assets/avatars/cpu/`: アバター4点
- `docs/assets/README-hero-proj-poker.png`: ヒーロー画像
- `README.md`: 日本語の代替テキスト付き画像参照

## 確認結果

- PowerShellのZIP一覧確認により、指定のPNG10点が揃っていることを確認。
- System.Drawingで全画像を読み込み、寸法・形式を確認。ロゴ・ボタン・アバター6点はアルファチャンネルを持ち、隅の透明度が0。
- 画像一覧を目視確認。ユーザー提供のPNGは加工せず使用。
- 登録先のGit blob SHAとローカル画像から算出したSHAが10点すべて一致。
- READMEの相対参照先が配置済み画像と一致。
- アプリ実装・package.json・CIがまだ存在しないため、ビルドや自動テストは未実施。テストコードの追加なし。

## 方針・残課題

- D60に従い、カード表面・チップの構造描画は今回の対象外。
- アバター4点の追加でCPU poolの人数・人物設定を確定しない。
- コンポーネント境界・Event・永続化設計は変更しないため、アーキテクチャ・データ設計書の更新は不要。
- ヒーロー画像は完成イメージであり、アプリの実装済み画面ではない。READMEの実装前表記を保持する。
- PRタイトルはユーザー明示指定の「assets: 初期UIアセット一式を追加」を優先。
- ローカルGitの通信が利用できないため、GitHub連携APIで既存mainを親にしたコミットと新規ブランチを作成する。
- マージは今回の依頼に含まれない。
