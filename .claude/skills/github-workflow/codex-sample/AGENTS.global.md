# Codex グローバル レビュー指針

このファイル（`~/.codex/AGENTS.md`）は Codex の全リポジトリ共通のレビュー指針です。
プロジェクト固有の観点は、各リポジトリ直下に置く `AGENTS.md` に記載します
（テンプレート: `CLAUDE-assets/<user>/CLAUDEmd/AGENTS.md`）。

## Review guidelines

- **日本語**でレビューする。
- 重大度の高い問題に集中する。各指摘の**行頭に重大度タグ**を付ける（自動判定で使用するため必須）:
  - `[P0]` リリース/運用を止める致命的な問題（データ損失・セキュリティ侵害・ビルド破壊・明確なバグ）
  - `[P1]` 次のサイクルで必ず直すべき重要な問題
  - `[P2]` / `[P3]` は任意（軽微・改善提案）。多用しない。
- 重点観点:
  - **正確性**: ロジック誤り・境界条件・null/未定義・競合・例外経路。
  - **セキュリティ**: 機密情報の漏洩、インジェクション、認証/認可、権限昇格、危険なコマンド実行。
  - **破壊的変更・互換性**: 公開 API・スキーマ・設定の後方互換性。
  - **エラーハンドリング**: 失敗時の挙動・リソース解放。
- スタイルや好みの指摘は、明確な根拠がない限り避ける。
- 推測が必要な箇所や、人間の判断が要る設計判断は**その旨を明示**する（勝手に断定してマージ可否を誤らせない）。
- 指摘は簡潔に。「何が問題か」「なぜ問題か」を述べ、可能なら対象の `ファイル:行` を示す。
- 重大な問題がなければ「**指摘なし**」と明記する。
- コメント冒頭には必ず `[codex]` タグを付ける。レビューが自身の GitHub アカウント経由で投稿されるため、人間のレビューと区別できるようにするため。
